## 二、字段说明

| 字段 | 必填 | 取值/格式 | 说明 |
|------|------|-----------|------|
| 序号 | ✅ | 3 位数字 001/002 | 唯一标识，便于引用 |
| 源库 | ✅ | 源数据库名 | 如 prd_spark_db / test_zxbs_db |
| 源表名 | ✅ | 源表名 | 不含库名前缀，不含反引号 |
| 源系统 | ✅ | MySQL / Xihe / MC | Xihe=阿里Spark引擎；MC=已是MaxCompute语法 |
| 目标库 | ✅ | MC 项目名 | 迁移后的 MaxCompute project |
| 目标表名 | ✅ | 迁移后表名 | 决定生成的 DDL/DML 文件名与表名 |
| 层级 | ✅ | ODS / DWD / DWS / ADS / DIM | 数仓分层 |
| 同步方式 | ✅ | full / incr / cdc | full=全量；incr=增量；cdc=实时 |
| 写入模式 | ✅ | OVERWRITE / INTO / MERGE | OVERWRITE=覆盖分区；INTO=追加；MERGE=主键更新 |
| 分区 | ✅ | 字段/粒度 或 - | 如 pt/d、ds/d、data_date/m；无分区填 - |
| 表类型 | ✅ | 普通 / Delta | 普通=aliorc分区表；Delta=主键表(transactional) |
| 主键 | ✅ | 字段名组合 或 - | Delta 表必填；普通表填 - |
| 负责人 | ✅ | 人名 | 该表的迁移负责人 |
| 备注 | ❌ | 自由文本 | 补充 LIFECYCLE、特殊说明、推断依据等 |

## 三、填写约定

1. **一行一表**：每个迁移表占一行，不要合并。
2. **表名不含反引号/库名前缀**：源表名和目标表名只写纯表名，库名单独放「源库/目标库」列。
3. **分区列格式固定**：`字段/粒度`，粒度用单字母 `d`(日)/`m`(月)/`y`(年)；无分区填 `-`。
4. **写入模式与表类型匹配**：
   - Delta 主键表 → 只能用 `MERGE`
   - 普通分区表 → `OVERWRITE`（推荐）或 `INTO`
   - 普通非分区表 → `INTO`（追加，不能 OVERWRITE）
5. **主键列**：Delta 表必填（如 `bill_app_no`、`project_code,contract_number`），普通表填 `-`。
6. **源系统决定迁移工作量**：
   - `MySQL` → 类型/约束/索引全改
   - `Xihe` → 函数/语法改，类型基本兼容
   - `MC` → 仅按规范补注释/调整属性
7. **新增表追加在表格末尾**，序号递增，不要插在中间打乱顺序。
8. **表名变更不要删旧行**，在备注标注「已废弃，新表见序号 XXX」。
9. **无法确认的字段**填 `<待确认>`，禁止留空或猜。

## 四、使用方式

填完映射表后，告诉我「映射表已更新」，我会：

1. 按目标表名生成对应的 DDL 脚本到 `迁移SQL脚本/01_DDL/<层级>/` 下
2. 按同步方式+写入模式生成对应的 DML 脚本到 `迁移SQL脚本/02_DML/<层级>/` 下
3. 按表名生成数据校验脚本到 `迁移SQL脚本/05_数据校验/` 下
4. 每个脚本按 `MaxCompute_SQL注释规范.md` 补全注释

> ⚠️ **当前待确认项**（影响 Delta 表生成）：
> - 001/002 主键未提供（Delta 表必须有主键才能写 MERGE）
> - 003 的 `_incr_t` 后缀含义未确认（推断为每日全量快照覆盖，写入模式暂标 OVERWRITE）

### 005 dwd_auto_oapi_loan_incr_delta（车贷放款信息表）

- 源表：`prd_spark_db.dwd_auto_oapi_loan_d`
- 目标表：`prod_dw_01.dwd_auto_oapi_loan_incr_delta`
- 表类型：Delta 事务主键表（`transactional=true`）
- 主键：`bill_app_no`
- 分区：`pt`（STRING，yyyymm，同 ods 一致）

```sql
CREATE TABLE IF NOT EXISTS dwd_auto_oapi_loan_incr_delta(
    id                  STRING        COMMENT '唯一编码',
    oapi_project_id     STRING        COMMENT '立项id',
    tenant_id           STRING        COMMENT '租户ID',
    channel_id          STRING        COMMENT '资产方固定特殊唯一编码',
    recon_date          STRING        COMMENT '对账日期',
    product_no          STRING        COMMENT '产品编码',
    bill_app_no         STRING NOT NULL COMMENT '借款申请编号',
    loan_req_no         STRING        COMMENT '放款流水号',
    loan_status         STRING        COMMENT '放款状态',
    loan_day            STRING        COMMENT '放款时间',
    loan_month          STRING        COMMENT '放款月份',
    date_due            STRING        COMMENT '到期日期',
    name                STRING        COMMENT '用户姓名',
    id_card_type        STRING        COMMENT '用户证件类型',
    id_card             STRING        COMMENT '用户身份证号码',
    contract_amt        DECIMAL(17,2) COMMENT '合同金额(元)',
    loan_amt            DECIMAL(17,2) COMMENT '放款金额(元)',
    service_amt         DECIMAL(17,2) COMMENT '前期服务费金额(元)',
    guarantee_amt       DECIMAL(17,2) COMMENT '前期担保费金额(元)',
    margin_amt          DECIMAL(17,2) COMMENT '前期保证金金额(元)',
    compensate_amt      DECIMAL(17,2) COMMENT '前期代偿金金额(元)',
    act_service_amt     DECIMAL(17,2) COMMENT '实收前期服务费金额(元)',
    act_guarantee_amt   DECIMAL(17,2) COMMENT '实收前期担保费金额(元)',
    act_margin_amt      DECIMAL(17,2) COMMENT '实收前期保证金金额(元)',
    act_compensate_amt  DECIMAL(17,2) COMMENT '实收前期代偿金金额(元)',
    repay_day           STRING        COMMENT '还款日',
    total_term          BIGINT        COMMENT '总期数',
    detail_status       STRING        COMMENT '借据状态',
    remark              STRING        COMMENT '备注',
    created_by          STRING        COMMENT '创建用户ID',
    last_modified_by    STRING        COMMENT '修改用户ID',
    create_time         STRING        COMMENT '创建时间',
    update_time         STRING        COMMENT '修改时间',
    dw_create_time      STRING        COMMENT '数仓创建时间',
    dw_update_time      STRING        COMMENT '数仓更新时间',
    PRIMARY KEY (bill_app_no)
)
PARTITIONED BY (pt STRING COMMENT '分区字段：yyyymm 同ods一致')
STORED AS aliorc
TBLPROPERTIES (
    'acid.data.retain.hours' = '0',
    'cdc.data.retain.hours' = '24',
    'columnar.nested.type' = 'true',
    'comment' = '车贷放款信息表',
    'transactional' = 'true',
    'acid.cdc.mode.enable' = 'false',
    'write.bucket.num' = '16'
);
```
