# DMS+Xihe → DataWorks+MaxCompute 迁移项目

> 数仓迁移项目文档库，包含迁移注意事项分析、DataWorks+MC 学习笔记与迁移 SQL 脚本。

## 项目背景

- **源平台**：阿里云 DMS + Xihe（湖仓一体 SQL 引擎）
- **目标平台**：阿里云 DataWorks + MaxCompute（一站式开发治理 + 数仓引擎）
- **目标**：完成数仓平滑迁移，保障数据一致性与业务连续性

## 使用方式

### 迁移阶段
1. 先阅读 [迁移注意事项/README.md](./迁移注意事项/README.md) 了解整体流程
2. 按 01-10 顺序逐项分析
3. 边迁移边补充实际遇到的问题到 10_常见问题与风险清单

### 学习阶段
1. 先阅读 [DataWorks_MC学习/README.md](./DataWorks_MC学习/README.md) 了解学习路径
2. 按 01-03 建立概念
3. 按需深入 10-34 系列
4. 结合迁移项目实践

### 脚本执行阶段
1. 阅读 [迁移SQL脚本/README.md](./迁移SQL脚本/README.md) 了解目录与命名规范
2. 按以下顺序执行：
   - `07_权限/01_角色创建` → 建立角色
   - `01_DDL/` → 建表（ODS→DWD→DWS→ADS→DIM）
   - `03_数据集成/` → 数据同步
   - `02_DML/` → ETL 开发（按层顺序）
   - `06_UDF/` → 注册函数
   - `04_调度/` → 配置调度
   - `05_数据校验/` → 双跑对账
   - `08_性能优化/` → 优化调整
3. 新建脚本时复制对应模板文件
