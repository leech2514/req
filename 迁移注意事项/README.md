## 迁移阶段建议流程

1. **调研评估**：盘点 DMS/Xihe 现有元数据、任务、依赖、调度、权限
2. **方案设计**：制定表/任务映射表、双跑策略、回滚预案
3. **环境准备**：DataWorks 工作空间、MC 项目、RAM、数据源
4. **迁移开发**：DDL → DML → 调度 → 数据集成 → 权限
5. **双跑验证**：并行运行、对账、性能对比
6. **割接上线**：流量切换、停旧任务、监控
7. **收尾归档**：文档归档、复盘、清理旧资源

## 关键风险提示

- Xihe 与 MC 在 **隐式类型转换、字符串函数、日期函数** 上差异较大，需逐个核对
- 调度依赖在 DataWorks 中以 **节点输出名** 为准，与 Xihe 的任务依赖机制不同
- MC 的 **分区表** 必须显式声明分区字段，且分区字段不能参与 DDL 字段定义
- 数据集成任务迁移时注意 **时区、字符集、精度截断** 问题
- MC 计费按 **存储 + 计算** 双重计费，需评估成本
