# 09 成本与性能优化

## 9.1 计费模型差异

| 维度 | DMS/Xihe | DataWorks + MaxCompute |
|------|---------|----------------------|
| 计费方式 | 按量/包年 | MC（按量/包年）+ DataWorks（按量/包年） |
| 存储计费 | 通常含在引擎中 | MC 独立计费（按存储量） |
| 计算计费 | 按扫描量 | 按 **CU** 或 **扫描量** |
| 数据集成 | 含在 DMS | 独立计费（按量/包年） |

## 9.2 MaxCompute 计费模式

### 按量计费（Pay-As-You-Go）
- 计算：按 SQL 扫描数据量计费（元/GB）
- 存储：分层计费（0-1GB 免费，阶梯价）
- 适合：任务量波动大、初期评估

### 包年包月（Subscription）
- 按 CU 预付费
- 适合：稳定生产、任务量明确

### 建议
- 初期按量 → 稳定后转包年
- 大表加分区，避免全表扫描

## 9.3 性能优化要点

### SQL 优化
- [ ] 利用 **分区裁剪**：所有查询带分区条件
- [ ] 避免 `SELECT *`，只查必要字段
- [ ] JOIN 时小表放右侧（MC 优化器较新版本可不依赖）
- [ ] 使用 `MAPJOIN` 提示小表广播
- [ ] 避免数据倾斜：skewjoin / 随机前缀

### 表设计优化
- [ ] 合理分区（分区粒度与查询匹配）
- [ ] 大表考虑 **分桶**（CLUSTERED BY）
- [ ] 高频聚合用 **物化视图**
- [ ] 配置 **生命周期** 自动回收

### 资源优化
- [ ] 长任务拆分
- [ ] 配置任务优先级与并发
- [ ] 评估独占资源组必要性

## 9.4 成本监控

- DataWorks 提供费用中心
- 监控：单任务费用、项目总费用、异常增长告警
- 定期 review 高消耗任务
