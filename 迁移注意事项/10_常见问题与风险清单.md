# 10 常见问题与风险清单

## 10.1 已知坑点

### SQL 层面
| 问题 | 现象 | 解决方案 |
|------|------|---------|
| 标识符引号 | 反引号 vs 双引号 | 全局替换 `"` → `` ` `` |
| 字符串拼接 | `||` 不支持 | 改用 `concat()` |
| 隐式转换 | 类型不一致 | 强制 `CAST` |
| NULL 排序 | 升序 NULL 位置不同 | 显式 `COALESCE` 处理 |
| 日期函数名 | `date_diff` vs `datediff` | 逐个核对 |
| 正则语法 | Presto vs Java regex | 测试验证 |

### 调度层面
| 问题 | 现象 | 解决方案 |
|------|------|---------|
| 依赖未生效 | 下游先跑 | 检查输出名配置 |
| 参数未传入 | SQL 中变量为空 | 检查参数赋值 |
| 跨周期依赖 | 跨天数据未就绪 | 配置跨周期依赖 |
| 补数据范围错误 | 误跑大量任务 | 谨慎选择范围 |

### 数据层面
| 问题 | 现象 | 解决方案 |
|------|------|---------|
| 时区错位 | 时间差 8 小时 | 统一项目时区设置 |
| 字符集乱码 | 中文乱码 | 检查源头编码 |
| 精度丢失 | 金额差异 | DECIMAL 替代 DOUBLE |
| 分区缺失 | 数据查不到 | 检查分区填充逻辑 |
| 主键冲突 | 重复行 | 业务层保证唯一 |

### 权限层面
| 问题 | 现象 | 解决方案 |
|------|------|---------|
| 表无权限 | Permission denied | 显式 GRANT |
| 跨项目访问失败 | 找不到表 | 配置跨项目权限 |
| RAM 角色失效 | 任务报错 | 检查角色策略 |

## 10.2 风险等级清单

### 高风险（必须预案）
- 核心报表数据不一致
- 调度任务大面积延迟
- 生产数据丢失

### 中风险（需关注）
- 个别字段类型转换异常
- 性能回退超过 50%
- 权限申请响应慢

### 低风险（持续优化）
- 个别非核心任务报错
- 成本高于预期
- 元数据不完整

## 10.3 降级方案

- **数据层降级**：新平台异常 → 切回旧平台
- **任务层降级**：复杂任务拆解为简单任务
- **报表层降级**：T+1 改 T+2，先保证准确性
- **告警机制**：自动检测 + 人工介入
