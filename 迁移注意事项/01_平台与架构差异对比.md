# 01 平台与架构差异对比

## 1.1 平台定位

| 维度 | DMS + Xihe | DataWorks + MaxCompute |
|------|-----------|----------------------|
| 核心定位 | 数据管理 + 湖仓一体 SQL 引擎 | 一站式数据开发治理平台 + 仓库引擎 |
| 计算引擎 | Xihe（基于湖仓的 Presto-like 引擎） | MaxCompute（分布式数仓引擎） |
| 元数据 | DMS 元数据 + 数据库原生 catalog | DataWorks 数据地图 + MC 元数据 |
| 调度 | DMS 任务编排 | DataWorks 调度（基于 ODPS 节点） |
| 数据集成 | DMS 数据流转 | DataWorks 数据集成 |

## 1.2 架构差异要点

- Xihe 多为 **联邦查询**，可直查 OSS/MySQL 等；MC 强调 **数据入仓后计算**
- DataWorks 是 **Studio 式**开发平台，比 DMS 更适合规范化数仓开发
- MC 对 **分区表、桶表、物化视图** 的支持更完整，但语法与 Xihe 不同
