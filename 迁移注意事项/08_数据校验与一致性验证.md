# 08 数据校验与一致性验证

## 8.1 验证目标

迁移后必须保证：
1. **数据量一致**：行数、分区数对齐
2. **数据值一致**：关键字段值对齐
3. **业务结果一致**：下游报表/指标对齐
4. **性能可接受**：核心任务运行时长可控

## 8.2 验证策略

### 双跑对账（推荐）
- 新旧平台并行运行 N 天（建议 7 天）
- 每日对账：表行数、汇总金额、关键指标
- 差异容忍度：金额类 0，计数字段 < 0.01%

### 分层校验

| 层级 | 校验内容 | 方法 |
|------|---------|------|
| ODS | 行数、字段非空 | count 对比 |
| DWD | 主键唯一、外键关联 | 抽样 join |
| DWS | 汇总值 | sum/avg 对比 |
| ADS | 报表指标 | 业务方确认 |

### 抽样校验
- 随机抽取 N 条记录逐字段对比
- 关注 NULL、空字符串、精度差异

## 8.3 对账脚本模板

```sql
-- 行数对账
SELECT 'mc_table' src, COUNT(*) cnt FROM mc_table WHERE ds='${bizdate}'
UNION ALL
SELECT 'xihe_table' src, COUNT(*) cnt FROM xihe_table WHERE ds='${bizdate}';

-- 金额对账
SELECT 'mc' src, SUM(amount) total FROM mc_table WHERE ds='${bizdate}'
UNION ALL
SELECT 'xihe' src, SUM(amount) total FROM xihe_table WHERE ds='${bizdate}';
```

## 8.4 常见差异原因

| 现象 | 可能原因 | 排查方向 |
|------|---------|---------|
| 行数差异 | 时区/分区间隔 | 检查分区定义与时间口径 |
| 金额差异 | 精度丢失 | DECIMAL vs DOUBLE |
| NULL 增多 | 类型转换失败 | 检查 CAST |
| 字符串不同 | 编码/trim | 检查字符集与空格 |
| 重复行 | 去重逻辑差异 | 检查 DISTINCT |

## 8.5 回滚预案

- 旧平台 **保留运行 2-4 周**，确保新平台稳定
- 关键任务配置 **一键切回** 机制
- 数据回滚：保留旧平台数据快照
- 监控告警：新平台异常自动通知
