# 03 数据类型映射

## 3.1 基本类型对照

| Xihe 类型 | MaxCompute 类型 | 注意事项 |
|-----------|----------------|----------|
| `BOOLEAN` | `BOOLEAN` | 一致 |
| `TINYINT` | `TINYINT` | 一致 |
| `SMALLINT` | `SMALLINT` | 一致 |
| `INTEGER` / `INT` | `INT` | 一致 |
| `BIGINT` | `BIGINT` | 一致 |
| `REAL` | `FLOAT` | 名称不同 |
| `DOUBLE` | `DOUBLE` | 一致 |
| `DECIMAL(p,s)` | `DECIMAL(p,s)` | MC 最大精度 38 |
| `VARCHAR(n)` | `VARCHAR(n)` | MC 写入受 8MB 限制 |
| `CHAR(n)` | `CHAR(n)` | 一致 |
| `STRING` | `STRING` | 一致 |
| `BINARY` | `BINARY` | 一致 |
| `VARBINARY` | `BINARY` | MC 无 VARBINARY |
| `DATE` | `DATE` | 一致 |
| `TIME` | - | MC 无 TIME，用 STRING 或 TIMESTAMP |
| `TIMESTAMP` | `DATETIME` / `TIMESTAMP` | **重点：精度与时区** |
| `JSON` | `STRING` + JSON 函数 | MC 原生 JSON 类型有限 |

## 3.2 复杂类型

| Xihe | MaxCompute |
|------|-----------|
| `ARRAY<T>` | `ARRAY<T>` |
| `MAP<K,V>` | `MAP<K,V>` |
| `ROW(...)` | `STRUCT<...>` |
| 嵌套 JSON | `STRING` + `get_json_object` |

## 3.3 重点风险

### 时间类型
- Xihe `TIMESTAMP` 默认 **UTC**，MC `DATETIME` 默认 **项目时区**
- 跨时区数据迁移需统一校准，建议迁移前明确项目时区设置
- MC `TIMESTAMP` 类型（新）带时区，`DATETIME` 不带，需二选一

### 字符串长度
- MC 单行所有 VARCHAR 总长度上限 **8MB**，Xihe 限制不同
- 长文本字段建议改用 `STRING`

### 数值精度
- MC `DECIMAL` 精度上限 38 位，超出需拆分或改 STRING
- `DOUBLE` 在聚合时可能产生精度漂移，关键金额字段用 DECIMAL
