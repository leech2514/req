# 07 权限与安全迁移

## 7.1 权限体系对比

| 维度 | DMS | DataWorks + MaxCompute |
|------|-----|----------------------|
| 账号体系 | DMS 用户 | RAM 子账号 / RAM 角色 |
| 项目空间 | 数据库实例 | MC 项目空间（Project） |
| 权限粒度 | 库/表/列 | 项目/表/列/资源/函数 |
| 权限模型 | DMS 权限 | MC ACL + Policy + RBAC |
| 数据安全 | 脱敏规则 | 数据保护伞 + 动态脱敏 |

## 7.2 迁移要点

### 账号体系
- [ ] RAM 子账号规划（按角色分组）
- [ ] 关键操作使用 RAM 角色（避免 AK 泄露）
- [ ] 旧 DMS 账号权限映射到新 RAM 账号

### 项目空间
- 单工作空间 vs 多工作空间（按业务域划分）
- 开发环境与生产环境隔离（DataWorks 标准模式）
- 跨项目访问需显式授权

### 表级权限
- 开发环境：宽松，方便调试
- 生产环境：严格，按需授权
- 敏感字段（手机号、身份证）启用 **数据保护伞** 脱敏

## 7.3 安全合规

- 数据保护伞：敏感数据识别 + 动态脱敏 + 审计
- 数据下载审批：生产数据导出需审批
- 操作审计：所有 DDL/DML 留痕
- 数据加密：MC 支持存储加密
