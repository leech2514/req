## 命名规范

### SQL 文件命名
```
<层>_<表名>_<操作类型>.sql
```

| 操作类型 | 缩写 | 示例 |
|---------|------|------|
| 建表 | ddl | `dwd_trade_order_di_ddl.sql` |
| 全量刷新 | df | `dws_trade_user_1d_df.sql` |
| 增量刷新 | di | `dwd_trade_order_di.sql` |
| 对账 | chk | `dwd_trade_order_chk.sql` |
| 建视图 | view | `ads_user_profile_view.sql` |
| 建物化视图 | mv | `dws_trade_user_mv.sql` |

### 内容规范
每个 SQL 文件包含：
```sql
-- ===================================================
-- 脚本名称: dwd_trade_order_di.sql
-- 所属层级: DWD
- 业务域: 交易域
-- 功能描述: 订单明细日增量 ETL
-- 源表: ods_mysql_order_di
-- 目标表: dwd_trade_order_di
-- 调度参数: ${bizdate}
-- 负责人: xxx
-- 创建日期: 2026-08-13
-- 修改记录:
--   2026-08-13 初版
-- ===================================================
```

## 迁移执行顺序

按以下顺序执行脚本：

1. **环境准备**：07_权限/01_角色创建
2. **建表**：01_DDL/（按 ODS → DWD → DWS → ADS → DIM 顺序）
3. **数据集成**：03_数据集成/（先离线全量初始化，再增量）
4. **ETL 开发**：02_DML/（按层级顺序）
5. **UDF 注册**：06_UDF/03_函数注册
6. **调度配置**：04_调度/
7. **数据校验**：05_数据校验/
8. **性能优化**：08_性能优化/

## 注意事项

- 所有 SQL 必须包含分区过滤条件（避免全表扫描）
- 生产环境执行前先在开发环境测试
- DDL 操作不可回滚，谨慎执行
- DML 使用 `INSERT OVERWRITE` 避免重复数据
- 大表操作评估成本与性能
