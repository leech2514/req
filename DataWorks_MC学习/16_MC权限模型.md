# 16 MC 权限模型

## 16.1 权限体系概览

MaxCompute 提供多种权限模型：
- **ACL**：基于对象的访问控制列表
- **Policy**：基于策略的访问控制
- **RBAC**：基于角色的访问控制
- **Package**：跨项目权限共享
- **Project**：项目级授权

## 16.3 ACL 授权

### 语法
```sql
-- 授权
GRANT <actions> ON <object_type> <object_name> TO USER <user>;

-- 撤销
REVOKE <actions> ON <object_type> <object_name> FROM USER <user>;

-- 示例
GRANT Read, Select ON TABLE orders TO USER RAM$xxx:subuser;
GRANT Describe, Select ON TABLE orders PARTITION (ds='20260813') TO USER ...;
```

### actions 列表
- `Read` / `Write`
- `Select`
- `Describe`
- `Alter`
- `Update`
- `Drop`
- `CreateTable` / `CreateFunction` / `CreateResource`
- `List`
- `All`

### object_type
- `TABLE`
- `RESOURCE`
- `FUNCTION`
- `INSTANCE`
- `PROJECT`

## 16.4 RBAC 授权

### 创建角色
```sql
CREATE ROLE role_name;
```

### 授权给角色
```sql
GRANT Read, Select ON TABLE orders TO ROLE role_name;
```

### 把角色授予用户
```sql
GRANT ROLE role_name TO USER RAM$xxx:subuser;
```

## 16.5 Package 跨项目授权

### 项目 A（源）
```sql
-- 创建 package
CREATE PACKAGE package_name;

-- 添加资源到 package
ADD TABLE orders TO PACKAGE package_name;

-- 允许项目 B 安装
ALLOW PROJECT project_b TO INSTALL PACKAGE package_name;
```

### 项目 B（目标）
```sql
-- 安装 package
INSTALL PACKAGE project_a.package_name;

-- 授权给用户
GRANT Read, Select ON PACKAGE package_name TO USER RAM$xxx:subuser;
```

## 16.6 DataWorks 中的权限管理

### 数据保护伞
- 敏感数据识别
- 动态脱敏
- 权限审批
- 操作审计

### 标准模式
- 开发环境：开发者自由访问
- 生产环境：严格授权 + 审批
- 发布流程：开发 → 提交 → 发布

### 成员管理
- 在 DataWorks 工作空间添加成员
- 关联 RAM 子账号
- 分配角色

## 16.7 最佳实践

- 生产环境使用 **RAM 角色**，避免 AK 泄露
- 敏感字段启用 **数据保护伞** 脱敏
- 跨项目访问用 **Package** 而非直接授权
- 权限变更走 **审批流程**
- 定期审计权限清单
