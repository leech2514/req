# 34 常见场景案例

## 34.1 用户画像

### 场景
- 整合用户行为、交易、属性数据
- 生成用户标签
- 支持营销、推荐

### 表设计
```sql
-- ODS
ods_mysql_user_info_df         -- 用户基本信息
ods_log_user_behavior_di       -- 用户行为日志

-- DWD
dwd_user_register_di           -- 注册明细
dwd_trade_order_di             -- 订单明细
dwd_log_user_action_di         -- 行为明细

-- DWS
dws_user_user_1d_df            -- 用户粒度1天汇总
dws_user_user_nd_df            -- 用户粒度N天汇总

-- ADS
ads_user_profile_df            -- 用户画像
ads_user_active_stat_df        -- 活跃统计
```

### 核心逻辑
```sql
-- 用户画像
INSERT OVERWRITE TABLE ads_user_profile_df PARTITION (ds='${bizdate}')
SELECT
    u.user_id,
    u.user_name,
    u.register_time,
    COALESCE(t.total_order_cnt, 0) total_order_cnt,
    COALESCE(t.total_pay_amount, 0) total_pay_amount,
    COALESCE(b.last_login_time, u.register_time) last_login_time,
    CASE
        WHEN COALESCE(t.total_pay_amount, 0) > 10000 THEN 'high'
        WHEN COALESCE(t.total_pay_amount, 0) > 1000 THEN 'mid'
        ELSE 'low'
    END user_level,
    (b.last_login_time >= DATE_ADD(TO_DATE('${bizdate}','yyyymmdd'), -7)) is_active
FROM dim_user_info_df u
LEFT JOIN (
    SELECT user_id, COUNT(*) total_order_cnt, SUM(amount) total_pay_amount
    FROM dwd_trade_order_di
    WHERE ds <= '${bizdate}'
    GROUP BY user_id
) t ON u.user_id = t.user_id
LEFT JOIN (
    SELECT user_id, MAX(action_time) last_login_time
    FROM dwd_log_user_action_di
    WHERE ds = '${bizdate}' AND action_type = 'login'
    GROUP BY user_id
) b ON u.user_id = b.user_id
WHERE u.ds = '${bizdate}';
```

## 34.2 订单分析

### 场景
- 订单量、GMV、转化漏斗
- 同比环比
- 渠道分析

### 表设计
```
ods_mysql_order_di              -- 订单原始
dwd_trade_order_di              -- 订单明细
dws_trade_order_1d_df           -- 订单日汇总
dws_trade_channel_1d_df         -- 渠道日汇总
ads_trade_order_stat_df         -- 订单统计
ads_trade_funnel_df             -- 转化漏斗
```

### 同比环比
```sql
SELECT
    cur.ds,
    cur.gmv,
    prev.gmv prev_gmv,
    (cur.gmv - prev.gmv) / prev.gmv gmv_growth,
    yoy.gmv yoy_gmv,
    (cur.gmv - yoy.gmv) / yoy.gmv gmv_yoy
FROM dws_trade_order_1d_df cur
LEFT JOIN dws_trade_order_1d_df prev
    ON DATE_ADD(TO_DATE(cur.ds,'yyyymmdd'), -1) = TO_DATE(prev.ds,'yyyymmdd')
LEFT JOIN dws_trade_order_1d_df yoy
    ON DATE_ADD(TO_DATE(cur.ds,'yyyymmdd'), -365) = TO_DATE(yoy.ds,'yyyymmdd')
WHERE cur.ds = '${bizdate}';
```

### 转化漏斗
```sql
SELECT
    step,
    COUNT(DISTINCT user_id) user_cnt
FROM (
    SELECT
        user_id,
        'visit' AS step,
        1 AS step_order
    FROM dwd_log_user_action_di
    WHERE ds='${bizdate}' AND action_type='visit'

    UNION ALL

    SELECT user_id, 'cart', 2
    FROM dwd_log_user_action_di
    WHERE ds='${bizdate}' AND action_type='cart'

    UNION ALL

    SELECT user_id, 'order', 3
    FROM dwd_trade_order_di
    WHERE ds='${bizdate}'
) t
GROUP BY step, step_order
ORDER BY step_order;
```

## 34.3 AB 实验

### 场景
- 实验分组
- 指标对比
- 显著性检验

### 表设计
```
dim_experiment_group_df         -- 实验分组
dwd_log_user_action_di          -- 用户行为
ads_experiment_metric_df        -- 实验指标
```

### 指标对比
```sql
SELECT
    experiment_id,
    variant,
    COUNT(DISTINCT user_id) user_cnt,
    SUM(amount) / COUNT(DISTINCT user_id) arpu
FROM dwd_trade_order_di o
JOIN dim_experiment_group_df g ON o.user_id = g.user_id
WHERE o.ds BETWEEN '${start}' AND '${end}'
  AND g.ds = '${end}'
GROUP BY experiment_id, variant;
```

## 34.4 留存分析

### 场景
- 用户次日/7日/30日留存
- 渠道留存

### 实现
```sql
SELECT
    register.ds register_date,
    action.ds action_date,
    DATEDIFF(TO_DATE(action.ds,'yyyymmdd'),
             TO_DATE(register.ds,'yyyymmdd'),'dd') retention_days,
    COUNT(DISTINCT register.user_id) register_cnt,
    COUNT(DISTINCT action.user_id) retention_cnt
FROM dwd_user_register_di register
LEFT JOIN dwd_log_user_action_di action
    ON register.user_id = action.user_id
    AND action.action_type = 'login'
    AND action.ds BETWEEN register.ds AND DATE_ADD(TO_DATE(register.ds,'yyyymmdd'), 30)
WHERE register.ds = '${bizdate}'
GROUP BY register.ds, action.ds;
```
