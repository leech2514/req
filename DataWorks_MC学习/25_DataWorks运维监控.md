# 25 DataWorks 运维监控

## 25.1 运维中心

### 功能模块
- 任务列表
- 实例管理
- 补数据
- 告警管理
- 运行历史

### 任务状态
| 状态 | 说明 |
|------|------|
| 未运行 | 等待调度 |
| 运行中 | 正在执行 |
| 成功 | 正常完成 |
| 失败 | 异常终止 |
| 超时 | 超过限制 |

## 25.2 实例管理

### 实例类型
- 周期实例：按调度自动生成
- 补数据实例：手动触发
- 临时实例：临时查询

### 操作
- 查看运行日志
- 重跑
- 设置成功 / 失败
- 终止运行

## 25.3 告警

### 告警类型
| 类型 | 触发条件 |
|------|---------|
| 任务失败 | 节点执行失败 |
| 任务超时 | 超过配置时长 |
| 基线告警 | 接近 SLA 时间 |
| 数据质量 | 质量规则失败 |
| 资源告警 | 资源组不足 |

### 告警方式
- 短信
- 邮件
- 钉钉
- 电话（高优先级）

### 配置
- 告警规则
- 接收人
- 时间窗口

## 25.4 补数据

### 场景
- 新任务上线初始化
- 数据修复
- 历史数据回刷

### 流程
1. 选择任务
2. 选择日期范围
3. 配置并发数
4. 选择下游影响范围
5. 提交执行
6. 监控执行情况

### 注意事项
- 大范围补数据评估资源
- 跨业务流程补数据谨慎
- 优先级可能影响正常任务

## 25.5 运行日志

### 日志类型
- 调度日志
- 任务日志（SQL 输出）
- 错误日志

### 排查
- 失败原因
- 执行计划
- 资源消耗
- 数据扫描量

## 25.6 监控大盘

### 指标
- 任务成功率
- 平均运行时长
- 资源利用率
- SLA 达标率

### 应用
- 日常巡检
- 异常发现
- 容量规划

## 25.7 应急响应

### 流程
1. 告警接收
2. 日志排查
3. 问题定位
4. 修复 / 回滚
5. 重跑 / 补数据
6. 复盘总结

### 预案
- 数据错误：修复 + 补数据
- 任务失败：定位 + 重跑
- 资源不足：扩容 + 调度
- 数据丢失：备份恢复

## 25.8 最佳实践

- 核心任务配置基线
- 告警分级（核心 / 一般）
- 定期巡检
- 建立值班机制
- 故障复盘
