# 24 DataWorks 数据治理

## 24.1 数据质量

### 质量规则
| 类型 | 示例 |
|------|------|
| 表级规则 | 表行数 > 0 |
| 字段级规则 | amount ≥ 0 |
| 主键唯一 | 主键不重复 |
| 外键完整性 | 外键必须存在 |
| 业务规则 | GMV 与昨日差异 < 10% |

### 配置
- 关联到节点
- 规则触发时机：节点运行后
- 强弱规则：强规则失败则任务失败

### 监控
- 质量分
- 趋势图
- 异常告警
