## 12.3 日期函数

| 函数 | 说明 | 示例 |
|------|------|------|
| `GETDATE()` | 当前时间 | 2026-08-13 10:00:00 |
| `CURRENT_DATE` | 当前日期 | 2026-08-13 |
| `TO_DATE(s,fmt)` | 字符串转日期 | `TO_DATE('20260813','yyyymmdd')` |
| `DATE_FORMAT(d,fmt)` | 日期格式化 | `DATE_FORMAT(d,'yyyy-MM-dd')` |
| `DATEADD(d,n,unit)` | 日期加减 | `DATEADD(d,1,'dd')` |
| `DATEDIFF(d1,d2,unit)` | 日期差 | `DATEDIFF(d1,d2,'dd')` |
| `DATE_TRUNC(d,unit)` | 截断 | `DATE_TRUNC(d,'mm')` |
| `YEAR(d)` / `MONTH(d)` / `DAY(d)` | 取年月日 | |
| `WEEKOFYEAR(d)` | 年中周数 | |
| `UNIX_TIMESTAMP(d)` | 转 unix 时间戳 | |
| `FROM_UNIXTIME(ts)` | unix 转日期 | |

### 日期格式符号
- `yyyy` 年 / `MM` 月 / `dd` 日
- `HH` 时 / `mm` 分 / `ss` 秒
- `yyyymmdd` 常用业务日期格式

## 12.5 窗口函数

| 函数 | 说明 |
|------|------|
| `ROW_NUMBER()` | 行号 |
| `RANK()` | 排名（并列跳号） |
| `DENSE_RANK()` | 排名（并列不跳号） |
| `NTILE(n)` | 分桶 |
| `LAG(col,n)` | 前 n 行 |
| `LEAD(col,n)` | 后 n 行 |
| `FIRST_VALUE(col)` | 首行 |
| `LAST_VALUE(col)` | 末行 |
| `PERCENT_RANK()` | 百分位排名 |
| `CUME_DIST()` | 累积分布 |

### 窗口范围
```sql
-- 从开头到当前行
ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW

-- 前 3 行到后 1 行
ROWS BETWEEN 3 PRECEDING AND 1 FOLLOWING

-- 整个分区
ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING
```
