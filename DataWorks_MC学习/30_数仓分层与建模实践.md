# 30 数仓分层与建模实践

## 30.1 分层架构

```
┌─────────────────────────────────────────┐
│  ADS（应用数据层）                       │
│  面向业务，结果表，报表直连              │
├─────────────────────────────────────────┤
│  DWS（汇总数据层）                       │
│  预聚合，按主题 + 周期汇总               │
├─────────────────────────────────────────┤
│  DWD（明细数据层）                       │
│  清洗 + 维度退化，明细事实               │
├─────────────────────────────────────────┤
│  DIM（维度层）                           │
│  缓慢变化维，统一维度                   │
├─────────────────────────────────────────┤
│  ODS（操作数据层）                       │
│  原始数据入仓，与源头一致                │
└─────────────────────────────────────────┘
```

## 30.2 ODS 层实践

### 设计要点
- 字段与源头一致
- 增量/全量明确
- 历史数据保留
- 来源标识

### 表设计
```sql
CREATE TABLE ods_mysql_order_di (
    id BIGINT COMMENT '订单ID',
    user_id BIGINT COMMENT '用户ID',
    amount DECIMAL(18,2) COMMENT '金额',
    create_time DATETIME COMMENT '创建时间',
    update_time DATETIME COMMENT '更新时间'
)
COMMENT 'MySQL订单表日增量'
PARTITIONED BY (ds STRING COMMENT '业务日期')
LIFECYCLE 365;
```

## 30.3 DWD 层实践

### 设计要点
- 维度退化（合并常用维度）
- 明细粒度
- 数据清洗
- 标准化

### 表设计
```sql
CREATE TABLE dwd_trade_order_di (
    order_id BIGINT COMMENT '订单ID',
    user_id BIGINT COMMENT '用户ID',
    user_name STRING COMMENT '用户名（退化）',
    sku_id BIGINT COMMENT '商品ID',
    sku_name STRING COMMENT '商品名（退化）',
    amount DECIMAL(18,2) COMMENT '订单金额',
    order_status STRING COMMENT '订单状态',
    create_time DATETIME COMMENT '下单时间',
    pay_time DATETIME COMMENT '支付时间'
)
COMMENT '交易域订单明细日增量'
PARTITIONED BY (ds STRING)
LIFECYCLE 720;
```

## 30.4 DWS 层实践

### 设计要点
- 预聚合
- 多周期（1d/7d/30d）
- 按主题汇总

### 表设计
```sql
CREATE TABLE dws_trade_user_1d_df (
    user_id BIGINT COMMENT '用户ID',
    order_cnt BIGINT COMMENT '下单数',
    order_amount DECIMAL(18,2) COMMENT '下单金额',
    pay_cnt BIGINT COMMENT '支付数',
    pay_amount DECIMAL(18,2) COMMENT '支付金额'
)
COMMENT '交易域用户粒度1天汇总全量'
PARTITIONED BY (ds STRING)
LIFECYCLE 365;
```

## 30.5 ADS 层实践

### 设计要点
- 面向应用
- 直接对接 BI
- 反范式

### 表设计
```sql
CREATE TABLE ads_user_profile_df (
    user_id BIGINT,
    user_name STRING,
    total_order_cnt BIGINT,
    total_pay_amount DECIMAL(18,2),
    last_login_time DATETIME,
    user_level STRING,
    is_active BOOLEAN
)
COMMENT '用户画像表'
PARTITIONED BY (ds STRING)
LIFECYCLE 90;
```

## 30.6 DIM 层实践

### 缓慢变化维（SCD）
| 类型 | 处理方式 |
|------|---------|
| SCD1 | 直接覆盖 |
| SCD2 | 历史版本（生效起止时间） |
| SCD3 | 增加历史字段 |

### 表设计
```sql
CREATE TABLE dim_user_info_df (
    user_id BIGINT,
    user_name STRING,
    phone STRING,
    email STRING,
    register_time DATETIME,
    is_valid BOOLEAN COMMENT '是否有效'
)
COMMENT '用户维度全量'
PARTITIONED BY (ds STRING)
LIFECYCLE 365;
```

## 30.7 建模流程

1. **业务调研**：理解业务过程
2. **数据域划分**：按领域分类
3. **维度识别**：提取维度
4. **事实表设计**：定义粒度
5. **汇总表设计**：定义聚合
6. **DDL 生成**：建表
7. **ETL 开发**：编写 SQL
8. **验证上线**：对账 + 发布
