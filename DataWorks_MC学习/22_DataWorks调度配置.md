# 22 DataWorks 调度配置

## 22.1 调度模型

### 调度层次
```
工作空间
  └── 业务流程
       └── 节点
            └── 实例（每次运行）
```

### 调度核心
- **节点输出名（output）**：节点唯一标识，依赖的基础
- **上游依赖（input）**：通过输出名引用上游
- **调度参数**：运行时变量
- **调度周期**：执行频率

## 22.2 节点输出名

### 规则
- 默认：`工作空间名.节点名`
- 自定义：可修改
- **全局唯一**

### 依赖建立
- 节点 A 输出：`project.node_a`
- 节点 B 上游依赖：`project.node_a`
- DataWorks 自动建立 A → B 依赖

### 跨流程依赖
- 通过输出名跨业务流程引用
- 跨工作空间需特殊配置

## 22.3 调度参数

### 系统参数
| 参数 | 含义 | 示例 |
|------|------|------|
| `${bizdate}` | 业务日期（T-1） | 20260812 |
| `${bizmonth}` | 业务月 | 202608 |
| `${bizyear}` | 业务年 | 2026 |
| `${tbizdate}` | 当天 | 20260813 |
| `${yyyymmdd}` | 业务日期 | 20260812 |
| `${yyyymm}` | 业务月 | 202608 |
| `${hhmmss}` | 运行时间 | 100000 |
| `${timezone}` | 时区 | Asia/Shanghai |

### 自定义参数
- 在节点参数配置区添加
- `${param_name}`
- 支持 `$[]` 格式（运行时计算）

### 参数赋值方式
```
# 在调度配置参数区
bizdate=$bizdate
offset=-1
```

### 跨节点传参
- 上游节点输出参数
- 下游节点通过 `${param}` 引用
- 依赖必须存在

## 22.4 调度周期

### 类型
| 类型 | 说明 |
|------|------|
| 分钟调度 | 每 N 分钟 |
| 小时调度 | 每 N 小时 |
| 日调度 | 每天 |
| 周/月调度 | 按周/月 |
| 年调度 | 按年 |

### 时间配置
- 开始时间
- 结束时间
- 重跑时间

### cron 表达式（部分场景）
```
0 0 2 * * ?  每天 2 点
0 */30 * * * ?  每 30 分钟
```

## 22.5 调度依赖

### 配置
- 节点配置 → 调度依赖
- 添加上游节点（按输出名）
- 依赖类型：普通依赖 / 跨周期依赖

### 跨周期依赖
| 类型 | 说明 |
|------|------|
| 同天依赖 | 依赖当天实例 |
| 跨天依赖 | 依赖昨天实例（自依赖） |
| 上一周期 | 依赖上一周期 |

## 22.6 基线

### 概念
- 定义任务承诺完成时间
- 超时告警
- 保障 SLA

### 配置
- 基线名称
- 优先级
- 承诺完成时间
- 告警方式（短信/邮件/钉钉）

### 类型
- **核心基线**：高优先级，监控核心任务
- **一般基线**：监控普通任务

## 22.7 资源组

### 调度资源组
- 任务执行的物理环境
- 共享 / 独享
- 与数据集成分组资源不同

### 选择
- 任务类型决定资源组类型
- SQL 任务用调度资源组
- 同步任务用集成资源组

## 22.8 任务优先级

- 数值越小，优先级越高
- 范围：1-1000
- 默认：根据基线自动计算
- 可手动调整

## 22.9 补数据

### 场景
- 历史分区数据回刷
- 数据修复
- 新任务上线初始化

### 操作
1. 选择任务
2. 选择日期范围
3. 配置并发
4. 提交执行
5. 自动触发下游

### 注意
- 补数据会触发依赖链
- 大范围补数据评估影响
- 生产环境谨慎操作

## 22.10 最佳实践

- 节点输出名规范化（与表名一致）
- 调度参数模板化
- 核心任务配置基线
- 跨周期依赖明确
- 补数据前评估范围
