# 03 核心概念术语表

## MaxCompute 术语

| 术语 | 英文 | 说明 |
|------|------|------|
| 项目空间 | Project | 顶级隔离单位，类似数据库 |
| 表 | Table | 数据存储单元 |
| 内部表 | Internal Table | 数据存储在 MC 内部 |
| 外部表 | External Table | 数据存储在外部（如 OSS） |
| 分区 | Partition | 逻辑数据划分 |
| 分区字段 | Partition Key | 分区标识字段 |
| 分桶 | Bucket | 表内数据分片 |
| 资源 | Resource | jar/py/file，供 UDF 使用 |
| 函数 | Function | 内建函数或 UDF |
| 实例 | Instance | 任务执行实例 |
| 隧道 | Tunnel | 数据上传下载通道 |
| 任务 | Job/Task | 一次计算作业 |

## DataWorks 术语

| 术语 | 英文 | 说明 |
|------|------|------|
| 工作空间 | Workspace | DataWorks 顶层管理单位 |
| 业务流程 | Business Flow | 节点的逻辑分组 |
| 节点 | Node | 最小调度单元 |
| 节点输出名 | Output | 节点唯一标识，用于依赖 |
| 上游依赖 | Dependency | 节点间依赖关系 |
| 调度参数 | Schedule Param | 节点运行时变量 |
| 调度周期 | Schedule Cycle | 节点执行频率 |
| 基线 | Baseline | SLA 保障规则 |
| 资源组 | Resource Group | 任务执行环境 |
| 数据源 | Data Source | 外部数据连接 |
| 数据集成分组资源 | DI Resource | 同步任务专用资源 |
| 业务日期 | BizDate | T-1 概念日期 |
| 数据地图 | DataMap | 元数据与血缘 |
| 数据保护伞 | Data Security Guard | 敏感数据保护 |
| 补数据 | Backfill | 历史分区回刷 |

## 数据集成术语

| 术语 | 说明 |
|------|------|
| 离线同步 | 批量同步，按调度执行 |
| 实时同步 | CDC 变更实时同步 |
| 整库同步 | 一次性同步整库 |
| 解决方案 | DataWorks 的同步模板 |
| 脏数据 | 同步失败或不符合规则的数据 |
| 游标 | 增量同步的位点 |

## 权限术语

| 术语 | 说明 |
|------|------|
| RAM | 阿里云资源访问控制 |
| RAM 用户 | 子账号 |
| RAM 角色 | 角色授权 |
| ACL | 访问控制列表 |
| Policy | 策略授权 |
| Package | 跨项目权限包 |
| Project Owner | 项目所有者 |
| Admin | 项目管理员 |

## 时区与时间

| 术语 | 说明 |
|------|------|
| 项目时区 | Project 默认时区（中国一般为 Asia/Shanghai） |
| 业务日期 | bizdate，前一天日期（T-1） |
| 调度日期 | 任务实际运行日期 |
| 数据日期 | 数据所属日期（=业务日期） |

## 常见缩写

| 缩写 | 全称 | 含义 |
|------|------|------|
| MC | MaxCompute | 阿里云数仓引擎 |
| ODPS | Open Data Processing Service | MaxCompute 旧名 |
| DW | DataWorks | 阿里云开发治理平台 |
| ODS | Operational Data Store | 操作数据层 |
| DWD | Data Warehouse Detail | 明细数据层 |
| DWS | Data Warehouse Summary | 汇总数据层 |
| ADS | Application Data Service | 应用数据层 |
| DIM | Dimension | 维度层 |
| CDC | Change Data Capture | 变更数据捕获 |
| SLA | Service Level Agreement | 服务等级协议 |
| UDF | User Defined Function | 用户自定义函数 |
| MV | Materialized View | 物化视图 |
