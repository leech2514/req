# 02 DataWorks 概览

## 2.1 产品定位

DataWorks 是阿里云 **一站式大数据开发治理平台**，基于 MaxCompute 等引擎，提供：
- 数据集成
- 数据开发
- 数据治理
- 数据安全
- 数据服务

## 2.2 模块组成

| 模块 | 功能 |
|------|------|
| 数据集成 | 离线/实时同步，多源互通 |
| 数据开发 | SQL/Shell/PyODPS 节点开发 |
| 数据建模 | 规范化维度建模 |
| 数据治理 | 数据质量、血缘、资产盘点 |
| 数据安全 | 数据保护伞、权限、脱敏 |
| 数据服务 | API 发布与订阅 |
| 运维中心 | 任务监控、补数据 |
| 数据地图 | 元数据检索与血缘 |

## 2.3 工作空间（Workspace）

- DataWorks 的 **最大管理单位**
- 关联一个或多个 MC Project
- 区分 **开发环境** 与 **生产环境**（标准模式）
- 成员角色：空间管理员 / 开发 / 运维 / 访客 / 安全管理员

## 2.4 核心概念

| 概念 | 说明 |
|------|------|
| 工作空间 | 顶层管理单位 |
| 数据源 | 外部数据连接 |
| 节点 | 最小调度单元 |
| 业务流程 | 节点组合 |
| 基线 | SLA 保障 |
| 调度资源组 | 任务执行环境 |
| 数据集成分组资源 | 同步任务专用资源 |

## 2.5 节点类型

| 类型 | 用途 |
|------|------|
| ODPS SQL | MC SQL 开发（最常用） |
| ODPS MR | MapReduce 作业 |
| Shell | 脚本任务 |
| PyODPS | Python + MC |
| 数据集成 | 同步任务 |
| 虚拟节点 | 占位/聚合依赖 |
| Do-While | 循环节点 |
| 分支节点 | 条件分支 |

## 2.6 标准开发流程

1. **数据集成**：将外部数据同步到 MC
2. **数据开发**：编写 SQL 处理数据
3. **调度配置**：配置周期、依赖、参数
4. **发布**：开发环境 → 生产环境
5. **运维监控**：监控任务状态、处理异常
6. **数据治理**：质量校验、血缘追踪

## 2.7 与 MaxCompute 的关系

- DataWorks 是 **开发治理层**
- MaxCompute 是 **计算存储层**
- DataWorks 调度任务实际在 MC 执行
- 用户主要在 DataWorks 界面操作，几乎不直接操作 MC
