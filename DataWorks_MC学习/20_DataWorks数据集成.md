# 20 DataWorks 数据集成

## 20.1 数据集成能力

### 同步类型
| 类型 | 说明 | 适用场景 |
|------|------|---------|
| 离线同步 | 批量同步，按调度执行 | 数仓 ETL |
| 实时同步 | CDC 变更实时同步 | 实时数仓 |
| 整库同步 | 一次性同步整库 | 上云初始化 |
| 解决方案同步 | 模板化同步 | 规范化场景 |

### 数据源类型
- **关系型**：MySQL / PostgreSQL / Oracle / SQL Server / DRDS
- **大数据**：Hive / HDFS / HBase
- **NoSQL**：MongoDB / Redis
- **文件**：OSS / FTP
- **消息**：Kafka / DataHub
- **阿里云**：MC / Tablestore / OpenSearch
- **API**：RESTful

## 20.2 离线同步配置

### 步骤
1. 配置源头数据源
2. 配置目标数据源（MC）
3. 选择表 / 字段映射
4. 配置同步策略（并发 / 通道）
5. 配置脏数据处理
6. 配置调度

### 字段映射
- 同名自动映射
- 手动调整映射
- 注意类型转换

### 同步策略
| 配置 | 说明 |
|------|------|
| 并发数 | 同时执行的 task 数 |
| 通道大小 | 单 task 吞吐 |
| 同步速率 | 限速保护源头 |
| 写入模式 | insert / replace / update |

## 20.3 实时同步

### CDC 数据源
- MySQL binlog
- PolarDB
- Oracle redo log

### 配置
1. 源端开启 CDC
2. 创建实时同步任务
3. 配置表映射（含 DDL 同步）
4. 配置目标表（MC 表需支持实时写入）

### 输出
- 实时写入 MC Delta 表
- 或写入 DataHub → Flink 处理

## 20.4 整库同步

### 场景
- 一次性上云
- 多表批量同步

### 配置
- 选择源头库
- 选择目标库
- 自动生成所有表的同步任务
- 配置过滤规则（表名 / 字段）

## 20.5 解决方案模式

### 特点
- 模板化、规范化
- 自动建表
- 自动生成任务
- 适合规范化数仓

### 配置
1. 选择源头
2. 配置目标命名规范
3. 配置同步规则
4. 一键生成

## 20.6 脏数据处理

### 配置
- 允许脏数据条数
- 允许脏数据比例
- 脏数据存储位置（OSS）

### 策略
- 严格模式：脏数据 > 0 即失败
- 宽松模式：允许一定比例
- 推荐：开发宽松，生产严格

## 20.7 资源组

### 类型
- **共享资源组**：默认，多租户
- **独享资源组**：专属，性能稳定
- **自定义资源组**：用户自管 ECS

### 选择
| 场景 | 推荐 |
|------|------|
| 开发测试 | 共享 |
| 生产稳定 | 独享 |
| 大表同步 | 独享（高配） |

### 配置
- 资源组规格（CPU/内存）
- 并发数
- 网络配置（VPC）

## 20.8 最佳实践

- 大表分片同步（按主键或时间）
- 增量同步优于全量
- 同步任务配置基线
- 监控同步延迟与脏数据
- 源头压力评估（避免影响业务库）
