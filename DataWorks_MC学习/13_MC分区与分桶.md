# 13 MC 分区与分桶

## 13.1 分区（Partition）

### 概念
- 分区是表的 **逻辑划分**
- 类似文件夹，每个分区独立存储
- 分区字段单独声明，不在字段列表中

### 建表
```sql
CREATE TABLE orders (
    order_id BIGINT,
    user_id BIGINT,
    amount DECIMAL(18,2)
)
PARTITIONED BY (ds STRING, pt STRING);
```

### 分区操作
```sql
-- 写入分区
INSERT OVERWRITE TABLE orders PARTITION (ds='20260813', pt='online')
SELECT order_id, user_id, amount FROM src;

-- 查询（分区裁剪）
SELECT * FROM orders WHERE ds='20260813';

-- 动态分区写入
INSERT OVERWRITE TABLE orders PARTITION (ds, pt)
SELECT order_id, user_id, amount, ds, pt FROM src;

-- 添加分区
ALTER TABLE orders ADD IF NOT EXISTS PARTITION (ds='20260813', pt='online');

-- 删除分区
ALTER TABLE orders DROP IF EXISTS PARTITION (ds='20260101');
```

### 分区设计原则
- **常用查询字段** 作为分区字段
- 分区层级建议 ≤ 3 级
- 单表分区总数 ≤ 6 万
- 第一级分区粒度：日/月
- 避免分区字段值过多（如 user_id 不可作分区）

### 分区裁剪
- 查询必须带分区过滤条件，否则全表扫描
- 分区字段做函数转换会失效：`WHERE SUBSTR(ds,1,6)='202608'` ❌
- 推荐改写：`WHERE ds >= '20260801' AND ds <= '20260831'` ✅

## 13.2 分桶（Bucket）

### 概念
- 分桶是分区内的 **物理分片**
- 按 HASH(字段) % 桶数 切分
- 用于优化 JOIN 与采样

### 建表
```sql
CREATE TABLE orders (
    order_id BIGINT,
    user_id BIGINT
)
PARTITIONED BY (ds STRING)
CLUSTERED BY (user_id) SORTED BY (user_id) INTO 32 BUCKETS;
```

### 适用场景
- 大表 JOIN（按相同字段分桶）
- 数据倾斜优化
- 抽样查询（TABLESAMPLE）

### 桶数选择
- 单分区数据量 / 100MB ≈ 桶数
- 一般 16/32/64
- 不宜过大（小文件问题）

## 13.3 聚簇（Cluster）

### 概念
- CLUSTERED BY + SORTED BY
- 提升范围查询性能

### 命令
```sql
ALTER TABLE orders CLUSTERED BY (user_id) SORTED BY (order_id) INTO 32 BUCKETS;
```
